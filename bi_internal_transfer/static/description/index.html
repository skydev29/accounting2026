What does this module do?
A purpose-built document for every cash/bank fund movement

The standard Odoo payment workflow is designed for customer/vendor transactions. Internal Transfers fills the gap by providing a dedicated, standalone model — account.internal.transfer — that handles all four fund-movement scenarios between your cash registers and bank journals. Every transfer creates a balanced, auditable journal entry and tracks the full lifecycle from draft to posted.

  • Confirm: validates both journals have a configured default account, creates and posts the journal entry, locks all fields.
  • Reset to Draft: voids and deletes the journal entry, returns all fields to editable state.
  • Cancel: voids and deletes the journal entry, sets state to Cancelled. The record is kept for audit history.

Installation & Configuration
Up and running in under two minutes

1 — Install the module

Go to Apps, search for Internal Transfers, and click Install. The menu item appears automatically under Accounting → Accounting → Internal Transfers.

2 — Verify journal default accounts

Navigate to Accounting → Configuration → Journals. For every cash or bank journal you intend to use as a source or destination, ensure the Default Account field is set. Journals created through the Odoo setup wizard are configured automatically.

3 — Create your first transfer

Click Accounting → Accounting → Internal Transfers → New, fill in the transfer type, source journal, destination journal, and amount, then click Confirm.

# CLI installation (Odoo.sh / self-hosted) odoo-bin -i bi_internal_transfer --stop-after-init --no-http

🔧 Developer Note — Dynamic Journal Domains The module uses two non-stored computed Char fields (journal_source_type, journal_dest_type) that are included as invisible fields in the form view. Odoo 19 evaluates the domain attribute of Many2one fields against the current record's field values at the client level, so these helpers make the journal dropdowns automatically filter to only cash or bank journals depending on the selected transfer type.
